DESIGN TASK
==================================================

Based on the information above, reason about how the available optimization
variables may influence the requested performance targets.

Use the historical context samples as empirical evidence for useful parameter-performance trends.

You are proposing ONE next seed for a costly active-learning iteration.
The best-known measured point is the primary local anchor. Prefer a conservative
local modification around this point when it is already close to satisfying all
targets. Do not make unsupported order-of-magnitude parameter changes merely
from generic circuit intuition. A large move away from the anchor is justified
only when the supplied measured historical evidence clearly supports that direction.

For multiplicative parameters, think in ratios rather than only absolute
differences. As a soft locality guideline, keep same-sign nonzero continuous
parameters approximately within anchor / 1.5 to anchor * 1.5. For fixed-negative
parameters, apply the factor to magnitude and restore the negative sign. This is
a search preference, not a hard admissibility constraint, and evidence may justify
a larger move.

When the anchor violates only one target slightly, prioritize improving that
violated target while preserving metrics that already satisfy their targets.
The objective is to find a feasible design efficiently, not to maximize
exploration or produce an extreme design.

The historical samples may cover only a small part of the full design space,
so do not assume that the best historical sample is necessarily the best possible design.

All target specifications must be considered jointly. The goal is to propose
a parameter point that moves toward satisfying ALL target specifications simultaneously.
Treat each target as a threshold for joint feasibility, not as a request to
optimize that metric as far as possible independently.

For each historical example, consider which specifications are violated and by how much.
Use normalized target violation as a directional reasoning concept:

- for a minimize metric, violation = max(0, (value - target) / abs(target));
- for a maximize metric, violation = max(0, (target - value) / abs(target)).

Prefer reducing the worst remaining normalized target violation rather than
maximizing or minimizing an already well-satisfied metric. Do not strongly
improve one metric at the cost of severely degrading another metric. Do not
optimize a metric far beyond its target while another metric remains strongly unsatisfied.

If a historical point is already close to satisfying all targets, prefer a
moderate modification around that promising region unless the historical data
provides clear evidence that a larger move improves the joint objective.

Use normalized violation only to guide the proposal. Do not output violations,
reasoning, confidence, explanations, or predicted metrics.
